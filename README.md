# Apocalypse Now!

A helicopter game in a single HTML file. Fly over five worlds, steal jeeps, and capture the flag.

**Play:** https://davidjrb.github.io/apocalypse-now/

Touch or mouse: drag to fly, hold still to brake. GUN and ROCKET buttons. Double-tap to land or take off.
On a Steam Deck, open the link in the browser and press F11 for full screen.

No build step and no dependencies: open `index.html` in any modern browser.
